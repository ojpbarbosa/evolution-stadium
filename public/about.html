why a stadium

This is how chips and antibodies are starting to be designed. We made it a sport so you can watch the method.

The loop is older than computers. Propose a change. Let something that cannot be argued with decide whether it is better. Keep the survivors, write down what you learned, go again. Breeders did it with wheat. Frances Arnold did it with enzymes and got a Nobel for it in 2018. In 2025 and 2026 the proposer became a language model and the loop got fast: AlphaEvolve found new matrix-multiplication algorithms by proposing code and keeping what a verifier accepted; auto-arch-tournament pointed the same loop at a RISC-V CPU and beat a human design by 26% on CoreMark per MHz, rejecting 63 of 73 hypotheses on the way. The agent never touches the judge. That line is the whole idea.

The problem with the method is that you cannot see it. A chip's fitness is a timing report. An antibody's is a binding energy. So we built the one version of the loop where the verifier is physics you can watch: creatures that have to walk.

What happens every generation

  1. Propose. Six coaches, each a language-model persona with a style and a creed, read the champion's genome, two alternates from the stable, the last sixteen notebook lines and the current course. Each returns one mutated genome and a hypothesis in twelve words: a causal claim, not a wish.
  2. Judge. Each genome is built as rigid boxes with motorised hinge joints in a physics engine and driven for seven seconds. The judge measures distance, how long the torso stayed upright, how much it bounced, and total motor amplitude. It is deterministic: the same genome always gets the same measurements. Coaches cannot touch it.
  3. Race. The best three are replayed live, same engine, same timestep, so the race on screen is exactly what was scored.
  4. Select. A proposal is kept only if it beats the record. Everything else goes into the notebook as rejected, with the delta and whether it fell. Four dry generations declare a plateau: a challenger lineage branches from the champion with one structural change (a leg dropped or added, a different torso), is protected in the stable for six generations, and the coaches must change structure, not numbers. The next generation's proposals are always built on the champion the heat just crowned, so a record is never followed by a wasted round.
  5. Values. Physics measures; the judge's table decides what counts. Three weights, speed, posture and economy, turn measurements into a score and re-score the whole stable when they change. The outcome of every run is also classified into a gait: walk, hop, shuffle, crawl, tumble, statue.

What is real and what is simulated

Real: the physics, the scores, the race, the notebook, the lineage, the crowd's votes and the judge's values. The coaches are a language model (the model name is on the scoreboard); their hypotheses are their own words. Simulated: the creatures, the course. Nothing in the loop is scripted, and a bad night for the coaches shows up on the scoreboard as a flat curve.

The ablation, which is the result

Switch the coaches to blind random mutation and nothing else changes: same engine, same budget of six proposals per generation, same stable. The bench runs both arms side by side and draws the two record curves. RoboMorph, the 2024 paper closest to this, never ran that baseline. We run it live, and we report it either way.

Where the idea comes from

  • Karl Sims, Evolving Virtual Creatures, 1994. The first creatures that learned to walk by evolution, and still the most watchable.
  • Frances Arnold, directed evolution of enzymes, Nobel Prize in Chemistry 2018. Propose, screen, keep, repeat, with chemistry as the judge.
  • Keiwan Donyagard, Evolution, 2017. A genetic-algorithm creature sandbox; the proposer there is random mutation.
  • RoboMorph, 2024 to 2026. A language model as the mutation operator for robot morphologies.
  • DeepMind, AlphaEvolve, 2025. Language-model proposals under an automated verifier, for algorithms.
  • Filipe Bonetto, auto-arch-tournament and HWE Bench, 2026. The same loop on a CPU, with formal proofs and an FPGA timing run as the judge. "The verifier is the artifact." This project is that sentence with a crowd.

Where it goes

Swap the judge and keep the stadium. A chip: the judge is synthesis, formal checks and a timing run, which already exist in auto-arch. An antibody: the judge is a binding-energy model. A bridge: a load test. The coaches, the stable, the notebook, the plateau protocol and the crowd do not change. The stadium becomes a benchmark for how well a model proposes under a verifier, which is the skill that matters now, and a way for people who are not engineers to watch it happen.
